🔐 Connexion personnelle

Utilise le même compte sur tes deux appareils. L'accès aux données est limité par les règles de sécurité de Supabase.

La première synchronisation peut importer les 54 véhicules et leur historique local si la base en ligne est vide. Si des véhicules existent déjà en ligne, l'application les charge sans écraser la base.

📦 Sauvegarde de secours

Exporte régulièrement un fichier JSON contenant les véhicules et l'historique. Cette copie est utile même lorsque la synchronisation cloud est active.

🚘 Gérer les véhicules

Tu peux remplacer les noms temporaires par les immatriculations réelles. Les audits restent associés au véhicule.

ℹ️ Si la synchronisation cloud est active, les changements enregistrés dans l'application sont envoyés à Supabase. La base doit avoir les tables vehicles et audits ainsi que les règles RLS créées avec le script SQL fourni précédemment.

🧹 Réinitialisation locale

Efface uniquement les données enregistrées dans ce navigateur, pas les données dans Supabase. Exporte d'abord une sauvegarde si nécessaire.
